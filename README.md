# מעבדות ביוטכנולוגיה

אתר שמרכז את שמונה מעבדות החובה במגמת ביוטכנולוגיה, למורי ולתלמידי הביוטכנולוגיה בישראל.
התוכן מבוסס על אוגדן מעבדות ביוטכנולוגיה (מור-טק, הטכניון, עבור משרד החינוך), מהדורת תשפ"ו.

## מה יש באתר

לכל מעבדה יש טאב, ובתוכו שלושה טאבים:

- **הוראות לתלמיד:** מטרה, רקע עיוני, מהלך הניסוי, שאלות לדיון ומושגי חובה לבגרות. מתחת להוראות יש **סימולציה אינטראקטיבית** של מהלך העבודה במעבדה.
- **הנחיות למורה:** מחוון לשאלות הדיון, הערות ודגשים להוראה.
- **הנחיות ללבורנט:** ציוד וחומרים לכל קבוצה, הכנת תמיסות והוראות בטיחות.

## מבנה הקבצים

```
BioLabs/
├── index.html      האתר כולו (קובץ אחד, בלי קבצים נוספים)
├── README.md       הקובץ הזה
└── docs/
    └── spec.md     אפיון המערכת
```

## איך פותחים את האתר

פותחים את `index.html` בדפדפן (לחיצה כפולה על הקובץ). האתר עובד גם בלי אינטרנט.

## איך מעלים לגיטהאב (GitHub Pages)

1. יוצרים repository חדש בגיטהאב.
2. מעלים אליו את הקבצים: **Add file** ← **Upload files**, וגוררים את `index.html`, `README.md` ואת תיקיית `docs`.
3. נכנסים ל-**Settings** ← **Pages**, בוחרים Branch: `main` ולוחצים **Save**.
4. אחרי דקה-שתיים האתר זמין בכתובת:
   `https://<שם-המשתמש>.github.io/<שם-ה-repository>/`

## הערות

- **גרסה נוכחית: גרסת מורים.** כל שלושת הטאבים גלויים. בגרסת התלמידים (בהמשך) התלמידים יקבלו קישור נפרד, ויראו רק את ההוראות לתלמיד ואת הסימולציה.
- **המספרים בסימולציות** (ערכי בליעה, נפחי טיטרציה) הם ערכים לדוגמה שמראים את המגמה הצפויה, ולא תוצאות אמיתיות.
- **מעבדה 5:** באוגדן מופיעים שני ריכוזים לתמיסת המלטוז (2.5 ו-1.5 מ"ג/מ"ל). באתר מופיע 1.5 מ"ג/מ"ל, לפי הטבלה והוראות ההכנה ללבורנט.
- **מעבדה 8:** השוק התרמי בערכת ה-CRISPR הוא ב-60°C (ולא ב-42°C כמו במעבדה 7).
